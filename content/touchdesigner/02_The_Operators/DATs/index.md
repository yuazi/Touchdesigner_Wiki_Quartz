DATs handle everything **text-based** in TouchDesigner — Python scripts, GLSL shader code, JSON, XML, and tabular data. They are the place where logic lives: `Execute` DATs fire scripts on events, `Table` DATs store structured data, and `Web Client` DATs pull in live data from APIs.

**Key nodes:** Table, Text, Select, CHOP Execute, DAT Execute, Web Client, JSON
