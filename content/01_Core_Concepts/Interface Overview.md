# Interface Overview

The TouchDesigner interface is a large, infinite canvas called the **Network Editor**.

## Major UI Elements
1. **Network Editor:** The main area where you place nodes.
2. **Parameters Window (P):** Where you edit node settings.
3. **Palette (L):** Access pre-built components and tools.
4. **Timeline:** Control the global playback.
5. **Textport (Opt+T or Cmd+Opt+T):** View Python errors and print output.

## Navigation
- **Right-Click:** Drag to pan the network.
- **Scroll Wheel:** Zoom in and out.
- **Left-Click:** Select nodes.
- **U:** Go up to the parent level.
- **I:** Go into the selected component.
